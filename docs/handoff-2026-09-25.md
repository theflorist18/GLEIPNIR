## 4. How to run things

| What | How |
|---|---|
| Web app | `http://localhost:8081` (the stack must be up) |
| Bench app | double-click `orchestration/benchapp.pyw`, or `pyw -3.11 orchestration\benchapp.pyw` |
| Frontend tests / build | `cd frontend && npx vitest run && npx vite build` |
| Bench tests | `python orchestration/test_benchapp.py && python orchestration/test_experiment.py` (Windows or WSL) |
| Gateway tests | `cd gateway && npm test` (81/81 after the dashboard removal) |
| Rebuild the frontend image | the frontend slice of `docs/audit/chunk-7-build-images.sh` (host MITM CA via `--build-context`), then in WSL: `cd network/compose && docker compose -p gleipnir -f compose-net.yaml -f compose-ca.yaml -f compose-services.yaml up -d --no-build --no-deps frontend` |
| Any WSL call from Windows | `wsl -d Ubuntu-22.04 -u root --exec bash -lc "…"`. Use **`--exec`**, not `--`: `--` re-parses through the default shell and empties `$vars` |

## 7. Rules that bit us (keep them)

- **Never** run `down.sh --wipe`, `docker compose down -v` or `docker volume rm` without explicit permission for
  that one time. Plain `down.sh` keeps the volumes. The app's backup and restore is the supported way around
  ledger resets.
- **Four gateway routes add an ACCESS event when read:** `GET /evidence/:id`, `/download`, `/export` and
  `/cases/:id/coc-report`. Opening an evidence detail page therefore changes the trail you are inspecting. To
  check the UI without touching real trails, serve `frontend/dist` with a canned `/api/v1` mock.
- **Rebuild images together with compose edits.** An old gateway image crashed once the results mount was removed.
- **Don't patch files with inline Bash heredocs** that contain backslashes (`\\b` became a backspace). Use a
  script file instead.
